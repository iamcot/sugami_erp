# Cấu hình AWS S3 cho Sugami (P3-01)

Sugami lưu ảnh/video trên bucket S3 có sẵn của shop, dưới một folder (prefix) riêng. Trình duyệt tải file **thẳng lên S3** bằng link ký sẵn (presigned URL), không đi qua iMac.

## 1. Key IAM chỉ được dùng folder của Sugami

IAM → Users → Create user `sugami-erp` (không cần quyền console) → Attach policy (JSON), thay `erp/` bằng folder của bạn:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:GetObject", "s3:PutObject", "s3:DeleteObject"],
      "Resource": "arn:aws:s3:::sugami.vn/erp/*"
    },
    {
      "Effect": "Allow",
      "Action": "s3:ListBucket",
      "Resource": "arn:aws:s3:::sugami.vn",
      "Condition": { "StringLike": { "s3:prefix": "erp/*" } }
    }
  ]
}
```

Tạo access key loại *Application running outside AWS*, điền vào `.env` trên iMac (không gửi qua chat).

## 2. CORS cho bucket (bắt buộc để upload từ trình duyệt)

S3 → bucket → **Permissions → Cross-origin resource sharing (CORS) → Edit**, dán:

```json
[
  {
    "AllowedOrigins": ["https://erp.sugami.vn", "http://localhost:3000"],
    "AllowedMethods": ["PUT", "GET", "HEAD"],
    "AllowedHeaders": ["Content-Type"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

Nếu bucket đã có cấu hình CORS cho việc khác, **thêm** khối trên vào mảng, đừng xóa khối cũ.

## 3. `.env`

```
STORAGE_DRIVER=s3
S3_REGION=ap-southeast-1      # xem ở tab Properties của bucket
S3_BUCKET=sugami.vn
S3_PREFIX=erp/                # folder đã tạo, có dấu / ở cuối
S3_ACCESS_KEY=...
S3_SECRET_KEY=...
S3_ENDPOINT=                  # để trống với AWS
S3_PUBLIC_BASE_URL=           # để trống nếu không dùng CloudFront (app dùng link ký sẵn 1 giờ)
```

Bucket tên có dấu chấm (`sugami.vn`) được app tự chuyển sang kiểu địa chỉ `s3.<region>.amazonaws.com/sugami.vn/...` để tránh lỗi chứng chỉ HTTPS.

## 4. Kiểm tra

```bash
pnpm storage:check
```

Script ghi một file nhỏ vào `<prefix>healthcheck/`, đọc lại, thử upload bằng link ký sẵn, rồi xóa. Thấy dòng `Lưu trữ hoạt động bình thường.` là xong. Dòng nào báo ✗ thì gửi nguyên dòng đó vào chat (không chứa key).

## Luồng upload trong app

1. `POST /api/media/uploads` `{ filename, contentType, sizeBytes }` → tạo `media_asset` (pending) + link PUT ký sẵn (15 phút, khóa đúng loại file và kích thước).
2. Trình duyệt `PUT` file lên link đó.
3. `POST /api/media/:id/complete` → API kiểm tra file đã có trên S3 và đúng kích thước → `ready`.

Giới hạn: ảnh (jpg, png, webp, gif, heic) và PDF 20 MB; video (mp4, mov, webm) 500 MB. Key: `<prefix>media/<năm>/<tháng>/<id>.<đuôi>`.

Dev không có S3: `STORAGE_DRIVER=local` (cần `APP_ENCRYPTION_KEY`), file nằm ở `STORAGE_DIR`, link upload trỏ về API.
